# MedScores V4.19

V4.19 focuses on branding consistency, lower-rank leaderboard organization, and Student Settings layout.

## Changes

- `public/logo.png` is the only logo/icon source referenced by app metadata and the install manifest.
- Removed the generated PWA/Apple icon assets introduced in V4.18 from the full project.
- Redesigned shared #4/#5 leaderboard ranks into structured rank strips with initials, code names, tie counts, and one shared score.
- Rebuilt Student Settings into three clear sections: Fingerprint, Change PIN, and Install MedScores.
- Student Settings uses a balanced two-column desktop layout and a clean stacked mobile layout.
- No database changes are required.
