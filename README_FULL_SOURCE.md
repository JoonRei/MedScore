# MedScores V3.6

V3.6 is a focused Student Home responsive refinement built on V3.5.

Highlights:
- Achievement Board/leaderboard no longer reserves large fixed desktop heights on phones and tablets.
- Podium height follows its real content, removing awkward vertical whitespace while preserving the existing V2.8/V2.9 design.
- Assessment title, max score, podium, tied students, ranks #4/#5, progress, and markers scale cleanly on narrow screens.
- Student Assessment Overview remains a compact 2 × 2 grid on phones instead of collapsing into one full-width item per row.
- Small-screen spacing and typography were tightened without changing leaderboard data or ranking logic.
- Existing Admin pages, security, raw-score logic, shared-rank handling, and other V3.5 functionality are unchanged.

No Supabase migration or environment-variable change is required.
